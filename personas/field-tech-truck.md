# Persona: Field Tech (on a truck)

**Who:** A field tech doing a quick count of truck stock between jobs. In a hurry,
on a smaller screen, half-distracted. Not a power user — taps around to find things.

**Login:** test account (logs in himself when prompted). If the app supports it,
resize the browser to a narrow/mobile viewport before starting so mobile layout
gets exercised.

**Primary goal:** Count the few items on the truck, fix an inevitable fat-finger,
submit, and get back to work fast.

**Believable path:**
1. Find the truck / vehicle sub-location (note how long it takes to find it — a
   hurried tech shouldn't have to hunt).
2. Count 3–4 items quickly.
3. Fat-finger one quantity (e.g. type 110 instead of 11), realize it, fix it.
4. Submit the count.
5. Confirm it actually saved (look for confirmation; if there's no clear
   confirmation, record that as a friction/clarity issue).

**Features this persona must cover:** mobile/narrow layout, location search/find,
fast count entry, in-line error correction, submit + save confirmation.

**What the tech cares about (capture in `felt`):** can he do this one-handed and
fast, is anything too small to tap, is it obvious the count saved, did the correction
actually stick.
